1. ปัญหาประเภทใด

Binary มีสองคลาส เช่น spam/ham; Multiclass มีหลายคลาสแต่หนึ่งแถวมีหนึ่งคำตอบ เช่นชนิดดอกไม้; Multilabel หนึ่งแถวมีหลายป้ายได้ เช่นบทความเป็นทั้งกีฬาและธุรกิจ Classification ทำนายหมวดหมู่ แม้โมเดลสร้าง probability ต่อเนื่องก่อนใช้ threshold

2. Decision Tree: เรียนรู้กฎแบ่งพื้นที่

  1. พิจารณา feature และ threshold ที่แบ่งข้อมูลใน node
  2. คำนวณ impurity หลัง split แบบถ่วงน้ำหนักจำนวนตัวอย่าง
  3. เลือก split ที่ลด impurity มากที่สุด แล้วทำซ้ำกับ child nodes
  4. หยุดตามข้อจำกัด เช่น max_depth, min_samples_split, min_samples_leaf แล้วใช้สัดส่วนคลาสในใบเป็นฐานการทำนาย
Gini = 1−Σpₖ² | Entropy = −Σpₖlog₂pₖ | Gain = impurity(parent)−Σ(n_child/n_parent)impurity(child)

โหนดมีสองคลาส 50:50 → Gini=0.5, Entropy=1 bit; โหนดบริสุทธิ์ → ทั้งคู่ 0 ตัวอย่าง parent 10 จุดแบ่ง 5:5 (Gini .5), child ขนาด 4 บริสุทธิ์และขนาด 6 มี 1:5 → weighted Gini=0.6×(1−1/36−25/36)=1/6 ดังนั้น gain=1/3

Tree จับ nonlinear/interactions ได้และอธิบายเส้นทาง if–then ได้ ไม่ต้อง scale เพื่อการเปรียบเทียบ threshold ของ feature แต่ต้นลึกมากเสี่ยงจำ noise ลด max_depth หรือเพิ่ม min_samples_leaf เพื่อ regularize; ข้อเสียคือเปลี่ยนข้อมูลนิดเดียวโครงสร้างอาจเปลี่ยนมาก

3. k-Nearest Neighbors

Euclidean: d(x,z)=√Σ(xⱼ−zⱼ)² | Manhattan: d(x,z)=Σ|xⱼ−zⱼ|

เก็บชุดฝึกไว้ คำนวณระยะจากจุดใหม่ เลือก k จุดที่ใกล้ที่สุด แล้วโหวตคลาสหรือถ่วงน้ำหนักตามระยะ จัดเป็น lazy learner เพราะต้นทุนสำคัญอยู่ขณะทำนาย แต่ยังมี fit เพื่อเก็บข้อมูลและสร้างโครงสร้างค้นหา

การตั้งค่าผลที่พบบ่อย
k เล็กขอบเขตซับซ้อน bias ต่ำ variance สูง ไวต่อ noise
k ใหญ่ขอบเขตเรียบ bias สูงขึ้น อาจกลบกลุ่มย่อย
weights="distance"เพื่อนใกล้มีอิทธิพลมากกว่า
Scalingป้องกันรายได้หลักแสนครอบงำอายุหลักสิบในการวัดระยะ
ระวังในข้อสอบ

เลือก k ด้วย validation/CV เท่านั้น การวน k แล้วเลือกจาก test ทำให้ test กลายเป็น validation ต้องมี final test ใหม่ที่ไม่เคยใช้ตัดสินใจ ข้อมูลมิติสูงทำให้ระยะห่างแยกเพื่อนบ้านยากขึ้น

4. Logistic Regression และ threshold

z = β₀+Σβⱼxⱼ ; p(y=1|x)=1/(1+e⁻ᶻ) ; predict 1 เมื่อ p≥t

z=0 → p=.5; z≈1.099 → p≈.75 ชื่อมีคำว่า Regression แต่ใช้ classification ในบริบทนี้ เรียนรู้ด้วย logistic loss ไม่ใช่ OLS สัมประสิทธิ์เพิ่ม log-odds: เมื่อ xⱼเพิ่ม 1 หน่วยและตัวอื่นคงที่ odds คูณ exp(βⱼ) ไม่ใช่ probability เพิ่ม βⱼ จุดเปอร์เซ็นต์

เมื่อ features ผ่าน StandardScaler การเพิ่มหนึ่งหน่วยหมายถึงเพิ่มหนึ่งส่วนเบี่ยงเบนมาตรฐานของ train การลด threshold ทำให้ทำนาย positive มากขึ้น recall ไม่ลดบน score ชุดเดิม แต่ precision ไม่จำเป็นต้องเปลี่ยนอย่างเคร่งครัดในทุกจุด ต้องเลือกจาก validation และต้นทุนจริง

ระวังในข้อสอบ

Logistic probability ไม่ได้รับประกันว่า calibrated สมบูรณ์ ขอบเขตตัดสินใจเป็นเส้นตรงใน feature space ที่ป้อน หากสร้าง nonlinear features ก็ได้เส้นโค้งใน input เดิม

5. Confusion Matrix ที่ต้องคำนวณเป็น

จริง \ ทำนายNegativePositive
NegativeTNFP
PositiveFNTP
Accuracy=(TP+TN)/N | Precision=TP/(TP+FP) | Recall=TP/(TP+FN)
Specificity=TN/(TN+FP) | F1=2TP/(2TP+FP+FN)

กำหนด positive เป็นกลุ่มที่สนใจ เช่น fraud ก่อนแทนสูตร สมมติ TP=30, FP=10, FN=20, TN=140 → accuracy=.85, precision=.75, recall=.60, F1=2/3, specificity=140/150≈.933

Precision ถามว่า “ที่แจ้งว่า positive เชื่อได้แค่ไหน”; Recall ถามว่า “positive จริงจับได้กี่ส่วน” หากต้นทุน FN สูงให้เน้น recall ภายใต้ข้อจำกัด FP; หาก FP แพงให้เน้น precision พร้อมติดตาม recall

ระวังในข้อสอบ

ข้อมูล positive 1% ทาย negative ทั้งหมดได้ accuracy 99% แต่ recall=0 จึงต้องดู confusion matrix และ metric ของคลาสเป้าหมาย หาก denominator เป็นศูนย์ต้องกำหนดวิธีจัดการ เช่น zero_division=0 และบอกบริบท

6. ROC, PR และการเฉลี่ยหลายคลาส

ROC แสดง TPR=recall เทียบ FPR=FP/(FP+TN) ขณะเปลี่ยน threshold; AUC ประเมินความสามารถจัดอันดับ score ไม่ใช่ accuracy ที่ threshold .5 ควรส่ง probability หรือ decision score แทน hard labels ในข้อมูล positive หายากให้ดู precision–recall และ Average Precision ประกอบ

Averageความหมายสิ่งที่ควรระวัง
Macroคำนวณ metric แต่ละคลาสแล้วเฉลี่ยเท่ากันเห็นปัญหาคลาสเล็กได้ดี
Weightedเฉลี่ยถ่วงด้วย support ของแต่ละคลาสคลาสใหญ่อาจกลบคลาสเล็ก
Microรวม TP/FP/FN ก่อนคำนวณsingle-label multiclass แบบรวมทุกคลาส micro P/R/F1 เท่ากับ accuracy
Multilabelคำนวณราย label/ราย sample ตามโจทย์subset accuracy ต้องตรงทั้งชุดป้ายจึงถูก เป็นเกณฑ์เข้มมาก
