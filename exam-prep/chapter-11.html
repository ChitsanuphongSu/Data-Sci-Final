1. Unsupervised ต่างจาก classification อย่างไร

Clustering ไม่มี label ที่กำหนดล่วงหน้าให้เรียนรู้ เป้าหมายคือกลุ่มที่คล้ายกันตาม features และนิยามระยะ เช่นแบ่งลูกค้าตามการใช้จ่าย ไม่ใช่ทำนายกลุ่มที่ผู้สอนเฉลยไว้ Cluster 0/1/2 เป็นเพียงชื่อเลข สลับกันได้และไม่มีลำดับสูงต่ำ

การใช้งานในบท: customer segmentation, anomaly detection และ topic modeling แต่ทั้งสามไม่จำเป็นต้องใช้ K-Means เสมอ สไลด์ยังกล่าวถึง PCA เพื่อลดมิติ และ LDA ซึ่งอาจหมายถึง Latent Dirichlet Allocation ใน topic modeling หรือ Linear Discriminant Analysis ใน supervised learning ต้องอ่านบริบท

2. K-Means แบบลงมือคำนวณ

J = ΣₖΣₓ∈Cₖ ||x−μₖ||² ; μₖ = ค่าเฉลี่ยเวกเตอร์ของสมาชิกกลุ่ม k
  1. เลือก K และเตรียม features ที่มีความหมาย จัดการ missing/outliers และพิจารณา scaling
  2. เริ่ม centers ด้วย k-means++ เพื่อให้จุดเริ่มต้นกระจายกันดี
  3. Assignment: ส่งแต่ละจุดไปยัง center ที่ใกล้ที่สุด
  4. Update: คำนวณค่าเฉลี่ยของสมาชิกแต่ละกลุ่มเป็น center ใหม่
  5. ทำซ้ำจนการเปลี่ยนแปลงต่ำกว่า tolerance หรือครบ max_iter; ทดลองหลาย initialization ด้วย n_init

ตัวอย่างข้อมูลหนึ่งมิติ [1,2,8,9], K=2, centers เริ่ม [1,8] → กลุ่ม [1,2] และ [8,9] → centers [1.5,8.5] → inertia=.25+.25+.25+.25=1

ระวังในข้อสอบ

K-Means ลด objective ตามการวนซ้ำแต่ไม่รับประกัน global optimum; เหมาะกลุ่มค่อนข้างกะทัดรัดตาม Euclidean distance อ่อนไหวต่อ outlier และกลุ่มวงแหวน/ความหนาแน่นต่างกัน Scaling เปลี่ยนน้ำหนักความสำคัญของ features จึงต้องมีเหตุผล ไม่ใช่ทำโดยไม่คิดทุกครั้ง

3. เลือก K อย่างมีเหตุผล

วิธีวิธีอ่านข้อจำกัด
Elbowพล็อต inertia ต่อ K หาจุดที่ประโยชน์เริ่มลดลงinertia ลดเมื่อ K เพิ่มอยู่แล้ว; จุดข้อศอกอาจไม่ชัด
Silhouetteวัดความใกล้กลุ่มตัวเองเทียบกลุ่มอื่นช่วง −1 ถึง 1; ต้องมี 2 ถึง n−1 labels และสอดคล้อง distance ที่เลือก
Stabilityเปลี่ยน seed/สุ่มข้อมูลแล้วกลุ่มยังคล้ายกันหรือไม่ชื่อเลขกลุ่มสลับได้ ต้องเทียบโครงสร้าง
Domain knowledgeตีความและนำไปใช้ได้ตามทรัพยากรK ที่คะแนนสูงสุดไม่จำเป็นต้องเหมาะธุรกิจที่สุด
s(i) = [b(i)−a(i)] / max(a(i),b(i))

a(i)=ระยะเฉลี่ยจากจุด i ถึงสมาชิกกลุ่มตนเอง; b(i)=ระยะเฉลี่ยต่ำที่สุดไปยังกลุ่มอื่น เช่น a=2,b=5 → s=.6 ใกล้ 1 แยกดี; ใกล้ 0 อยู่แถวขอบ; ติดลบอาจใกล้อีกกลุ่มกว่า สำหรับ singleton library กำหนด silhouette เป็น 0

หาก K=8 silhouette สูงสุด แต่ทีมรองรับ 4 กลุ่ม ให้เปรียบเทียบ K=4 ทั้งคะแนน ความเสถียร และ personas พร้อมอธิบาย trade-off ไม่ตัดสินจากงบหรือ score เพียงด้านเดียว

4. Cluster profiling

  1. รายงานจำนวนและสัดส่วนสมาชิกต่อกลุ่ม ตรวจกลุ่มเล็กผิดปกติ
  2. สรุป mean/median/spread ของ features ในหน่วยเดิม; inverse_transform centers หาก fit บน standardized features
  3. ทำ deviation heatmap เทียบค่าเฉลี่ยกลุ่มกับค่าเฉลี่ยรวมในหน่วยที่เปรียบเทียบได้
  4. ตั้งชื่อจากพฤติกรรมจริง เช่น “ซื้อบ่อย มูลค่าต่อบิลต่ำ” ไม่ตัดสินเชิงคุณค่าคน
  5. หารือผู้เชี่ยวชาญ ตรวจ interpretability, distinctiveness และ actionability แล้วเสนอแคมเปญ/การทดสอบผล

Random Forest ที่เรียนรู้ cluster labels ช่วยสำรวจ drivers ของการแบ่งกลุ่ม เป็นการอธิบายผลของอัลกอริทึมเดิม ไม่ใช่พิสูจน์ว่ากลุ่มเป็นความจริงภายนอกหรือเป็นเหตุของพฤติกรรม

5. สถิติเปรียบเทียบกลุ่ม

เครื่องมือคำถาม / สมมติฐานการอ่านผล
Shapiro–Wilk + Q-Q plotตรวจความสอดคล้องกับ normalityตัวอย่างมากทำให้ test ไวต่อความต่างเล็ก ๆ อย่าใช้ p-value ตัวเดียว
ANOVAเปรียบเทียบค่าเฉลี่ย กลุ่มอิสระ residual ใกล้ปกติและ variance เท่ากันในแบบคลาสสิกH₀: means เท่ากัน; reject บอกว่ามีอย่างน้อยหนึ่งกลุ่มต่าง ไม่บอกคู่ไหน
Kruskal–Wallisเปรียบเทียบ ranks ของกลุ่มอิสระตีความเป็นความต่าง median ได้เมื่อรูปทรงการแจกแจงเหมาะสม/คล้ายกัน ไม่ใช่ทดสอบ mean
η²SS_between / SS_totalสัดส่วนความแปรปรวนที่สัมพันธ์กับการแบ่งกลุ่มในข้อมูลชุดนี้

เกณฑ์ η²≈.01/.06/.14 ที่บทเรียนให้เป็น small/medium/large เป็นแนวอ้างอิงทั่วไป ต้องดูบริบทด้วย p-value คือความน่าจะเป็นของสถิติที่อย่างน้อยสุดโต่งเท่าที่สังเกตภายใต้ H₀ และสมมติฐาน ไม่ใช่ P(H₀ เป็นจริง) และไม่บอกขนาดหรือมูลค่าของผล

ระวังในข้อสอบ

ข้อจำกัดเพิ่มเติม: ถ้าสร้าง clusters ด้วยยอดซื้อ แล้วทดสอบว่ายอดซื้อแต่ละ cluster ต่างกันบนข้อมูลเดิม ความต่างถูกสร้างโดยอัลกอริทึมอยู่แล้ว p-value แบบมาตรฐานไม่ใช่หลักฐานยืนยันกลุ่มอิสระ ควรมองเป็น profiling เชิงสำรวจ และใช้ข้อมูล/ผลลัพธ์ภายนอกพร้อมแผน validation สำหรับข้อสรุปยืนยัน

6. ข้อสรุปที่ดีควรเขียนอย่างไร

“K=4 ให้ silhouette … กลุ่ม A มีสมาชิก …% มียอดซื้อต่อบิลสูงกว่าค่ากลางรวม … หน่วย เสนอทดสอบข้อเสนอเฉพาะกลุ่ม โดยวัดการตอบสนองเทียบ baseline ทั้งนี้ features และ scaling ที่เลือกมีผลต่อกลุ่ม และยังไม่ยืนยันเหตุและผล” เติมเฉพาะตัวเลขที่คำนวณจริง

ทำไมไม่เลือก K ด้วย inertia ต่ำสุด?

เพราะเพิ่ม K จนทุกจุดเป็นกลุ่มตัวเองทำให้ inertia เป็นศูนย์ แต่ไม่ได้สรุปข้อมูลอย่างมีประโยชน์ ต้องชั่ง separation, simplicity และการใช้งาน
