1. Simple และ Multiple Linear Regression

ŷ = β̂₀ + β̂₁x | ŷ = β̂₀ + Σⱼ β̂ⱼxⱼ | eᵢ = yᵢ − ŷᵢ

Simple มีตัวแปรต้นหนึ่งตัว; Multiple มีหลายตัว β₀ คือค่าคาดหมายเมื่อ features ทุกตัวเป็นศูนย์ ซึ่งอาจอยู่นอกช่วงข้อมูลและไม่มีความหมายเชิงใช้งาน βⱼ คือการเปลี่ยนค่าคาดหมายของ y ต่อ xⱼ หนึ่งหน่วยเมื่อ features อื่นคงที่ เป็นความสัมพันธ์เชิงโมเดล ไม่ใช่หลักฐานเหตุและผล

ตัวอย่าง ŷ = 12000 − 800×distance: เพิ่มระยะทาง 1 กม. คาดว่าค่าเช่าลด 800 บาท ที่ 3 กม. คาด 9,600 บาท หากจริง 10,000 บาท residual = +400 แปลว่าทำนายต่ำกว่าจริง

OLS: minimize SSE = Σᵢ(yᵢ − ŷᵢ)² | MSE = SSE/n

เมื่อ n คงที่และไม่มี penalty การลด SSE กับ MSE ให้ minimizer ชุดเดียวกัน Simple OLS: β̂₁ = Σ(x−x̄)(y−ȳ)/Σ(x−x̄)² และ β̂₀=ȳ−β̂₁x̄ ต้องมีความแปรปรวนของ x มากกว่าศูนย์

2. Metrics พร้อมคำนวณจริง

Metricสูตรตีความ
MAEΣ|e| / nหน่วยเดียวกับ y; ทุกความผิดพลาดมีน้ำหนักเชิงเส้น
MSEΣe² / nหน่วย y²; ลงโทษ error ใหญ่แรงกว่า
RMSE√(Σe²/n)หน่วยเดียวกับ y; ไวต่อ error ใหญ่
R²1 − SSE/SST, SST=Σ(y−ȳ)²เทียบกับ baseline ทำนายค่าเฉลี่ยของ y ในชุดประเมิน
Adjusted R²1 − (1−R²)(n−1)/(n−p−1)ปรับโทษจำนวน predictors p; ใช้เมื่อ n>p+1

ให้ y=[3,5,7], ŷ=[2,5,9] → e=[1,0,−2], SSE=5, MAE=1, MSE=5/3, RMSE≈1.291, SST=8, R²=0.375 ถ้าหน่วย y คือ kWh ค่า MAE=1 หมายถึงผิดเฉลี่ยแบบค่าสัมบูรณ์ 1 kWh ไม่ใช่ถูก 99%

ระวังในข้อสอบ

R² ติดลบได้เมื่อแย่กว่าทำนายค่าเฉลี่ย; ไม่ใช่เปอร์เซ็นต์ความถูกต้อง รายงานหน่วยและ baseline เสมอ เมื่อ y คงที่ R² มีกรณีพิเศษทางนิยาม ไม่ควรตีความแบบทั่วไป

Training R² ของ OLS ที่มี intercept จะไม่ลดเมื่อเพิ่ม predictors บนแถวเดิม แต่ validation R² อาจลด และ Adjusted R² ลดได้ ไม่ควรใช้ adjusted R² แทนการประเมินข้อมูลใหม่เพียงอย่างเดียว

3. Assumptions และการอ่าน residual

สิ่งที่ตรวจลักษณะที่ควรเห็นอาการผิดปกติ / วิธีคิด
Linearity ของ conditional meanresidual รอบศูนย์ไม่มีรูปแบบรูป U → อาจเพิ่ม polynomial หรือ feature ที่ขาด
Homoscedasticityความกระจาย error ใกล้เคียงกันรูปกรวย → heteroscedasticity; พิจารณา transform/วิธีประมาณ uncertainty ที่เหมาะ
Independenceerror ไม่สัมพันธ์ตามลำดับเวลาวิ่งเป็นช่วงบวก/ลบ → autocorrelation; ใช้ temporal split และ lag ที่รู้ ณ เวลาทำนาย
Normality ของ errorsQ-Q plot ใกล้เส้นเกี่ยวกับ inference แบบคลาสสิก ไม่ใช่เงื่อนไขว่า X และ y ต้องปกติจึงจะ fit ได้
Multicollinearitypredictors ไม่ซ้ำเชิงเส้นรุนแรงcoefficients ไม่เสถียร; VIFⱼ=1/(1−Rⱼ²), ดูเหตุผลและพิจารณา Ridge
Outlier / leverageไม่ถูกจุดเดียวกำหนดเส้นทั้งหมดตรวจสาเหตุและความผิดพลาดในการเก็บ ไม่ลบทิ้งเพื่อให้คะแนนดี

Residual plot บน validation 18 จุดเป็นเพียงหลักฐานจำกัด ไม่เห็นรูปแบบไม่ได้แปลว่า assumptions ผ่านทั้งหมด ถ้า residual บวกโดยรวม แสดงว่ามีแนวโน้มทำนายต่ำในชุดนั้น

4. Feature engineering และ basis expansion

Polynomial เปลี่ยน x เป็น [x,x²,…,xᵈ] แล้ว fit linear model จึงโค้งใน x แต่ยัง linear ใน coefficients สำหรับ x=2, degree=3, include_bias=False ได้ [2,4,8] ไม่ได้แถมคอลัมน์ 1 เพราะโมเดลมี intercept อยู่แล้ว

หลาย features จะมี interaction ด้วย เช่น [a,b] degree=2 ได้ [a,b,a²,ab,b²] หากมี 3 features และ degree=3 จะมี 19 features เมื่อไม่รวม bias ไม่ใช่เพียงเพิ่มกำลังแยกตัวละ 3 ค่า

Gaussian basis: φⱼ(x)=exp[−½((x−cⱼ)/σ)²] ; ŷ=β₀+Σβⱼφⱼ(x)

Gaussian basis ตอบสนองเฉพาะบริเวณใกล้ center ต่างจาก polynomial ที่ส่งผลทั่วช่วง ใน P05 centers กระจายเท่ากันระหว่าง train_min/train_max และ σ=width_factor×ระยะห่าง centers ตัวอย่างช่วง 0–10, N=6, width_factor=0.5 → centers ห่าง 2 → σ=1

ระวังในข้อสอบ

GaussianFeatures ในแล็บเป็น basis expansion สำหรับ regression ไม่ใช่ Gaussian Naive Bayes และไม่ใช่ Gaussian mixture clustering; ห้ามใช้ช่วง validation/test เพื่อกำหนด centers

5. Ridge, Lasso และการเปรียบเทียบอย่างยุติธรรม

วิธีรูป penaltyผลหลักและข้อจำกัด
OLSไม่มีbaseline เข้าใจง่าย; basis มาก/สัมพันธ์กันสูงอาจแกว่ง
RidgeL2: Σβ²หด coefficients; มักไม่ทำให้เป็นศูนย์พอดี ช่วยกรณี collinearity
LassoL1: Σ|β|บาง coefficients เป็นศูนย์ จึงเลือก feature ได้ แต่ correlated features อาจเลือกไม่เสถียร

เพิ่ม alpha คือเพิ่มความแรงของ penalty ภายใน estimator เดียวกัน ลด variance แต่แรงเกินไปทำให้ underfit ต้องเลือกด้วย validation/CV บน split เดียวกัน โดยทั่วไปควร scale เมื่อ features ต่างหน่วยเพื่อให้ penalty เปรียบเทียบ coefficients ได้อย่างเหมาะสม ไม่ใช่กฎว่าต้อง scale ซ้ำหากสเกลเหมาะแล้ว

scikit-learn Ridge: SSE + αΣβ² | Lasso: SSE/(2n) + αΣ|β|

alpha ตัวเลขเท่ากันข้ามสอง estimator จึงไม่รับประกันว่าแรงเท่ากัน ถ้าต้องการศึกษาผล penalty ให้ตรึง train/validation, basis, N, width และ scaler ให้เหมือนกัน แล้วเปลี่ยนเฉพาะ estimator ตาม protocol

กรณี p>n ใช้ได้ทั้ง Ridge และ Lasso เลือกตามสมมติฐานความ sparse, ความสัมพันธ์ features และ validation ไม่ใช่เห็น p>n แล้วต้องเลือก Lasso เสมอ

6. กระบวนการทำโจทย์ regression

  1. ระบุ y และหน่วย เลือก features ที่มีจริงขณะทำนาย
  2. แบ่งข้อมูลและทำ baseline → fit OLS บน train → วัด validation MAE/RMSE/R²
  3. ดู residual เทียบ fitted และเวลา เพื่อเสนอการปรับปรุงที่มีเหตุผล
  4. เปรียบเทียบ candidate โดยใช้แถวและ metric เดิม เลือกแบบง่ายกว่าเมื่อคะแนนใกล้กันตามกติกา
  5. ล็อกแบบและ refit เฉพาะเมื่อ protocol กำหนด จากนั้นรายงาน final test โดยไม่เลือกใหม่

ตอบจากความจำ

ทำไม polynomial degree สูงอาจ train ดีแต่ validation แย่?

ความยืดหยุ่นทำให้ fit noise และไวต่อชุดฝึก โดยเฉพาะปลายช่วงหรือ extrapolation ควรเลือก degree/penalty จาก validation และดูผลจริง

ช่วง bootstrap coefficient คือช่วง prediction ของวันใหม่หรือไม่?

ไม่ใช่ เป็นความไม่แน่นอนของค่าประมาณ coefficient ภายใต้การสุ่มซ้ำ; prediction interval ของ y ใหม่ต้องรวมความไม่แน่นอนของค่าคาดหมายและ noise ของ observation ใหม่
