กระบวนการตอบโจทย์ End-to-End

กรอบคิดที่ใช้ได้กับข้ออัตนัยและงานเขียนโค้ด

หน้ารวม
หนึ่งโจทย์ ต้องตอบให้ครบเจ็ดช่องFlow ที่ควรเขียนบนกระดาษสอบเลือกชนิดปัญหา → โมเดล → metricตรวจโค้ดผิดในข้อสอบแม่แบบตอบข้อวิเคราะห์ 5 ประโยค

หนึ่งโจทย์ ต้องตอบให้ครบเจ็ดช่อง

หัวข้อสิ่งที่ต้องระบุตัวอย่างค่าไฟ
Problemผู้ใช้และการตัดสินใจวางแผนพลังงานวันพรุ่งนี้
Targetค่าหรือ class และหน่วยenergy_kwh
Availabilityรู้ features เมื่อใดtemp_forecast_c ก่อนวันใช้งาน และ working_day
Splitจำลองโลกใช้งานจริงอดีต train → ช่วงถัดไป validation → อนาคต test
Baselineเกณฑ์พื้นฐานเปรียบเทียบค่าเฉลี่ย train หรือ Simple LinearRegression
Selectionmetric และกฎเลือกvalidation RMSE ต่ำสุด; tie เลือกง่ายกว่า
Reportผลจริงและข้อจำกัดMAE/RMSE/R², residual, ไม่อ้างเหตุและผล

Flow ที่ควรเขียนบนกระดาษสอบ

กำหนดโจทย์→กัน Test→Train + Pipeline→Validation / CV→ล็อกแบบ→ประเมิน Test

ถ้า validation ไม่ดี ให้ปรับในวง train/validation เท่านั้น ไม่ใช้ test เป็น feedback เมื่อทดสอบหลายแบบบน validation มาก ๆ ก็เสี่ยง overfit validation ได้ ควรมีขอบเขต candidate และเก็บ test แยก

เลือกชนิดปัญหา → โมเดล → metric

สิ่งที่ต้องการเริ่มทดลองประเมิน
ค่าต่อเนื่องDummy mean → Linear → Ridge/Polynomial → ForestMAE/RMSE/R² + residuals
คลาสที่มี labelDummy majority → Logistic → Tree/k-NN → Ensembleconfusion matrix + P/R/F1 + score-based AUC ตามบริบท
กลุ่มโดยไม่มี labelfeatures/scaling → K-Means หลาย Kinertia + silhouette + stability + profiling
เวลาหรือหลายแถวต่อคนเลือกโมเดลข้างต้นตาม targetเปลี่ยน split ให้ตรงเวลา/คนก่อนเลือก algorithm

# ถูก: fit preprocessing ใหม่เฉพาะ train ในแต่ละ fold
pipe = make_pipeline(StandardScaler(), Ridge(alpha=1.0))
scores = cross_val_score(pipe, X, y, cv=5,
                         scoring="neg_mean_squared_error")
  • พบ target หรือคอลัมน์หลังเหตุการณ์ใน X → ลบ/ออกแบบ features ใหม่ตามเวลา
  • พบวน hyperparameter แล้วเลือก test score สูงสุด → ย้ายการเลือกไป validation/CV
  • พบ scaler.fit_transform(X_test) → เปลี่ยนเป็น scaler.transform(X_test)
  • พบ hard labels ใน ROC-AUC → ใช้ probability/decision score
  • พบ shuffle ข้อมูลรายวันเพื่อทำนายอนาคต → พิจารณา temporal split
  • พบ KMeans labels แล้วเรียก accuracy โดยไม่มี reference → เปลี่ยนเป็น internal quality และ domain evaluation

แม่แบบตอบข้อวิเคราะห์ 5 ประโยค

1) โจทย์นี้เป็น … เพราะ target คือ … 2) แบ่งข้อมูลแบบ … เพราะการใช้งานจริง … 3) เลือก baseline/โมเดล … และทำ preprocessing … ภายใน train/fold 4) เลือกแบบด้วย … บน validation โดยให้ความสำคัญกับต้นทุน … 5) หลังล็อกแบบรายงาน test และข้อจำกัด … โดยไม่อ้างเกินหลักฐาน
