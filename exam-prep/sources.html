สไลด์เพิ่มเติมSVM/kernel และ dimensional reduction สรุปด้านล่าง

เนื้อหาเสริมจากสไลด์ Introduction

SVM เลือกขอบเขตที่ทำ margin กว้างโดยใช้ support vectors; soft margin ยอมละเมิดบางจุดและควบคุมด้วย C ข้อมูลที่แยกด้วยเส้นตรงไม่ได้อาจใช้ kernel เพื่อคำนวณความคล้ายใน feature space ที่ซับซ้อนขึ้น สไลด์หน้า 58–61 สาธิตการเพิ่มมิติ (x,y,x²+y²) เพื่อแยกวงแหวน ก่อนมองกลับเป็นขอบเขตโค้งใน 2D

PCA เป็น unsupervised dimensionality reduction หาแกนที่อธิบายความแปรปรวนมาก ไม่ใช้ y จึงไม่รับประกันว่าจะเก็บสัญญาณที่ดีที่สุดสำหรับ target หากใช้ก่อนโมเดล supervised ต้อง fit PCA ภายใน train/fold; LDA แบบ Linear Discriminant Analysis ใช้ label และต่างจาก Latent Dirichlet Allocation ที่ใช้ topic modeling

จุดที่เพิ่มความแม่นยำจากข้อความย่อในต้นฉบับ

ข้อความที่อาจทำให้เข้าใจผิดคำอธิบายในเว็บนี้

สไลด์หน้า26 ใช้ Bias ในสูตร errorสูตร squared error มาตรฐานใช้ Bias²
สไลด์หน้า53 กล่าว bootstrap ประมาณ33%Bootstrap ปกติสุ่ม n ครั้ง; OOB≈36.8%, unique in-bag≈63.2% เมื่อ n ใหญ่
Pipeline ป้องกัน leakage ได้ทั้งหมดช่วย preprocessing leakage ภายใน fold แต่ไม่แก้ future target หรือ group split ที่ผิด
ตัวอย่างเลือก k ด้วย test accuracyเว็บย้ายการเลือกไป validation/CV และเก็บ final test
Learning rate ยิ่งต่ำยิ่งดีต้องพิจารณาร่วมจำนวนรอบ เวลา และ validation
ต้อง scale เสมอทุกสถานการณ์พิจารณาหน่วยและ distance/penalty ที่ต้องการ ไม่ scale ซ้ำโดยไร้เหตุผล
p-value บอกความต่างไม่เกิดจากบังเอิญเป็น conditional tail probability ภายใต้ H₀/สมมติฐาน ไม่ใช่โอกาสที่ H₀ จริง
Kruskal เปรียบเทียบ median โดยไม่มีเงื่อนไขเป็น rank-based test; การตีความเฉพาะ median ต้องพิจารณารูปทรงการแจกแจง
ANOVA ยืนยัน clusters จาก feature เดิมอาจมี circularity; profiling และ independent validation เป็นคนละเป้าหมาย
